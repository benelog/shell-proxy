Shell Proxy

Two shells into this machine, and they are not the same tool with a different skin. Pick by what you need.

Stateless · JSON

Console /console

One command in, one JSON result out.

  • Structured result: exit code, stdout and stderr, separately
  • The same thing a script gets from /exec, so it is easy to automate
  • Nothing is kept between commands, and nothing is kept on the server
  • No terminal: vi and top cannot run here
  • Output arrives only when the command finishes, within 61 seconds
  • Each command starts a fresh shell, so cd does not stick

Live · PTY

Terminal /term

A real login shell in a PTY, streamed to your browser.

  • Full-screen programs work: vi, top, claude, colors, tab completion, Ctrl+C
  • Output streams as it happens, with no time limit
  • The session remembers its working directory, environment and history
  • Every tab is a separate shell; closing or reloading it ends that session for good
  • You get a stream of text, not a result a script can read
  • Unix only, and it is a full login shell, so treat it accordingly

Notice Both modes run as the account that started the server, over plain HTTP. Keep this on a trusted network.
